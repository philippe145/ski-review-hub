# ⛷️ 2026/27 Alpine Ski Review Hub & Guide

An interactive, single-page web application that aggregates grounded reviews, technical specs, and consensus evaluations for 2026/27 alpine skis across 15 global publications (including *SKI Magazine*, *SkiEssentials*, *InTheSnow*, *NeveItalia*, *Blister*, and *SKIMAGAZIN*).

## 🌟 Features

- **3 Dedicated Ski Categories**:
  1. **East Coast (Icy & Hard Snow)**: Mid-80 mm frontside carvers and edge-bite specialists (*Völkl Mantra 88*, *Blizzard Anomaly 88*, *Nordica Enforcer 89*).
  2. **Alps & Rockies (All-Mountain & Freeride)**: 96–108 mm wide-waist chargers built for variable snow and deep powder (*Völkl M7 Mantra*, *Blizzard Canvas 108*, *Salomon QST 106*).
  3. **Fast & Advanced Skiers (Race & Master GS/SL)**: High-performance race carvers and World Cup plate models (*Rossignol Hero Master LT R22*, *Head Worldcup Rebels e-Race Pro*, *Atomic Redster S9 Revoshock S*).

- **Interactive Ski Drawer / Modal**: Click on any ski card to open a deep-dive panel containing:
  - Technical construction specs (Woodcore, Titanal layers, binding plate interfaces, sidecut radius).
  - Aggregated multi-publisher review synthesis.
  - Strengths & weaknesses (pros/cons).
  - Best terrain and skier level recommendations.
  - Publisher citation tracking (including `(2025/26 test)` carryover designations).

- **Instant Search & Filtering**: Filter by category or search instantly across brand names, models, or keywords.
- **Zero External Dependencies**: Pure HTML5, CSS3, and Vanilla JavaScript—no build step, framework, or `npm install` required.

## 🚀 Quick Start / Deployment to GitHub Pages

### 1. Repository Setup
1. Create a new repository on GitHub (e.g., `ski-review-hub`).
2. Add two files to the root directory:
   - `index.html` (the web application code)
   - `README.md` (this file)

### 2. Enable GitHub Pages
1. Navigate to **Settings** → **Pages** in your GitHub repository.
2. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
3. Set the branch to **`main`** (or `master`) and folder to **`/ (root)`**.
4. Click **Save**. Your site will be live at `https://<your-username>.github.io/ski-review-hub/` in less than two minutes!

## 📊 Data & Review Sources

Reviews and technical specs are grounded in published gear tests across 15 international ski testing bodies:

- **North America**: *SKI Magazine*, *SkiEssentials*, *Blister*, *FREESKIER*, *OutdoorGearLab*, *Powder7*, *Christy Sports*.
- **Europe**: *NeveItalia* (Italy), *InTheSnow* (UK), *Fall-Line Skiing* (UK), *Snow Society / Snowplaza* (Austria/UK), *Snow-Online / World Ski Test* (Germany/Austria), *Schneehoehen.de* (Germany), *SKIMAGAZIN* (Germany), *Mon Séjour en Montagne* (France).
